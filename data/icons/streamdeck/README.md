# Stream Deck icons

Icons copied from the Elgato Stream Deck app on Windows (21/11/2026), for use by the Linux app.

| Folder | Content | Files |
|---|---|---|
| `packs/` | Key Creator icon packs (SVG). `icons.json` gives each icon a name and tags. | 2361 |
| `app/page-icons/` | Page icons shipped with the Stream Deck app | 327 |
| `app/touch-backgrounds/` | Touch strip backgrounds per device | 169 |
| `app/builtin-actions/` | Images of the built-in actions | 112 |
| `app/plugins/` | Images of the installed plugins | 723 |
| `custom/profiles/<profile>/<page>/` | Key images of the user's own profiles; `keys.json` maps each key position to its action and image | 145 |
| `custom/plugins/aiquota/` | Images of the AI Quota plugin | 16 |

## Licenses

- `packs/*`: MIT, Copyright Corsair/Elgato, see each `license.txt`. The `logoicons*` packs show third-party trademarks.
- `app/page-icons`, `app/touch-backgrounds`, `app/builtin-actions`: Stream Deck app assets, no license file.
- `app/plugins/<plugin>`: each plugin's own license.
